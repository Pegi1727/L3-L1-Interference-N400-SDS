# Figures and Visualizations

This directory contains high-resolution (300 DPI) figures and visual assets associated with the study **"L3-L1 Interference and N400 Dynamics."**

## Main Manuscript Figures
These figures are referenced directly in the main body of the manuscript.

- **`Fig1_Methodology_300dpi.png`**: Study design flowchart and experimental paradigm ($2 \times 3 \times 3$).
- **`Fig2_N400_300dpi.png`**: ERP waveforms and N400 mean amplitude across T1, T2, and T3.
- **`Fig3_RT_300dpi.png`**: Longitudinal trajectory of reaction times (Mismatch condition).
- **`Fig4_Calque_300dpi.png`**: Longitudinal progression of L1-induced calque errors.
- **`Fig5_Behavioral_Summary_300dpi.png`**: Comprehensive behavioral summary index (Delta Changes).

## Supplementary and Additional Visualizations
These files provide supporting evidence and graphical overviews for appendices.

- **`Brain_Behavior_Triangulation.png`**: Advanced visualization of brain-behavior triangulation.
- **`figure2_correlations.png`**: Detailed correlation plots supporting the findings in Table 5.
- **`Final_Visualization.png`**: Integrated summary of longitudinal findings.
- **`graphical-abstract.png`**: Concise visual abstract for rapid dissemination.

*Note: All images in this directory are exported at 300 DPI for high-quality printing.*
